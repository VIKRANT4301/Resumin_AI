# Resumin_AI 

An AI-powered resume analysis and optimization platform that helps candidates improve their resumes based on job descriptions using intelligent matching, ATS scoring, and AI-generated suggestions.

---

## 🌟 Features

* 📄 Resume Upload & Parsing
* 🤖 AI-Powered Resume Analysis
* 🎯 Job Description Matching
* 📊 ATS Compatibility Scoring
* 🧠 Smart Skill Gap Detection
* ✨ Resume Improvement Suggestions
* 🔍 Keyword Optimization
* 📈 Match Percentage Calculation
* 🌐 Modern Responsive UI
* 🔐 Secure Backend APIs

---

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone <PRIVATE_URL>
cd Resumin_AI
```

---

### 2️⃣ Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

### 3️⃣ Setup Backend

```bash
cd Backend

# Create virtual environment
python -m venv venv

# Activate virtual environment

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend server:

```bash
python app.py
```

Backend runs on:

```bash
http://localhost:5000
```

## 🔥 How It Works

1. Upload your resume (PDF/DOCX)
2. Paste the Job Description
3. AI analyzes:

   * Skills
   * Experience
   * ATS keywords
   * Missing requirements
4. Get:

   * Match Score
   * ATS Score
   * Suggestions
   * Improvement roadmap
